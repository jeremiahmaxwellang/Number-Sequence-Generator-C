# Number Sequence Generator (C)

## Main Menu Options:
1. Guessing the pattern to generate the fifth number in the sequence; 
2. Generating n numbers in a series given the pattern to follow;
3. Exit.

### Option 1
1. Increments of N 
2. Decrements of N 
3. Even Series 
4. Odd Series 
5. Prime Series 
6. +M +N Series 
7. -M -N Series 
8. +M -N Series 
9. -M +N Series 
10. *N Series 
11. Binary Series
