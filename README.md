# Number Sequence Generator (C)

## Main Menu Options:
1. Guessing the pattern to generate the fifth number in the sequence; 
2. Generating n numbers in a series given the pattern to follow;
3. Exit.

### Option 1
The program guesses the 5th number in a 4-integer sequence input by the user.
The following are the types of series:

1. Increments of N 
2. Decrements of N 
3. Even Series 
4. Odd Series 
5. Prime Series 
6. +M +N Series 
7. -M -N Series 
8. +M -N Series 
9. -M +N Series 
10. *N Series 
11. Binary Series

### Option 2:
The program generates N numbers in a series given a pattern.

The user chooses first which among the following will be generated:
1. Increments of N 
2. Decrements of N 
3. Incrementing Even Series 
4. Incrementing Odd Series 
5. Incrementing Prime Series 
6. [Go back to Main Menu]
